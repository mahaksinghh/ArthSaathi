Covexcode CLI used for QA

MoneyShield QR recipient mismatch · 25 November 2026

Recorded CLI session

$ covexcode --version
covexcode 1.18.0

Covexcode ran against a local Qwen2.5-0.5B-Instruct model. This is the prompt and reply captured during the review.

Prompt

ArthSaathi QR QA: scanned ID collection@demo; expected ID meera@demo. Are the two IDs different? Answer yes or no, then state the IDs.

CLI reply

No, the two IDs are not the same. The first ID is "arthSaathi@demo" and the second ID is "meera@demo".

Verified outcome

The CLI reply changed the scanned ID. We rejected that detail and added an automated test that checks the exact scanned ID, collection@demo. The QR is flagged High risk when the expected UPI ID is meera@demo, even though the amount matches.

This was a development QA review. Only fictional payment details were used.
